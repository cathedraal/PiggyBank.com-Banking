8

Data Security

We take the security of your personal data seriously and implement appropriate technical and organizational measures including:

  • End-to-end encryption for data in transit using TLS 1.3
  • Encryption of sensitive data at rest using AES-256
  • Multi-factor authentication for account access
  • Regular penetration testing and security audits
  • Automated fraud detection systems
  • Network firewalls and intrusion detection systems
  • Strict access controls — only authorized personnel can access your data
  • Regular staff training on data protection and security
  • Data minimization — we only collect what is necessary
  • Incident response procedures for data breaches
  • Regular review of our security practices

In the event of a personal data breach that poses a risk to your rights and freedoms, we will notify the relevant supervisory authority within 72 hours as required by GDPR Article 33. Where the breach is likely to result in a high risk to you personally, we will also notify you directly without undue delay.
